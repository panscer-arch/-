# Agency Agents

Локальная установка набора `agency-agents` из репозитория:
`https://github.com/msitarzewski/agency-agents`

Что установлено:
- агенты лежат в `.claude/agents`
- это профили и инструкции для Claude Code-стиля workflows
- в проект скопированы markdown-файлы агентов для локального использования и адаптации

Быстрые категории:
- `engineering-*` — разработка и архитектура
- `design-*` — UI/UX и визуальные роли
- `product-*` — продукт и исследования
- `testing-*` — тестирование и QA
- `project-management-*` — координация и delivery

Полезные файлы:
- `.claude/agents/README.md`
- `.claude/agents/QUICKSTART.md`
- `.claude/agents/agents-orchestrator.md`

Замечание:
Этот набор не является нативной системой Codex. Это библиотека агентских профилей, которую можно использовать как справочник, шаблоны ролей и основу для дальнейшей адаптации под наш текущий workflow.
