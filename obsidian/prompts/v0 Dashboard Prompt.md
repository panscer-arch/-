# v0 Dashboard Prompt

Готовый рабочий prompt для `v0` под `Dashboard`.

## Prompt

```text
Build a Telegram Mini App dashboard for the Lifecoding product using the connected GitHub repo as the source of truth.

Use these repo files as primary context:
- docs/dashboard-midfi-blueprint.md
- docs/component-spec.md
- docs/screen-roadmap.md
- docs/mvp-spec.md
- apps/web/app/globals.css

Important:
- mobile-first
- Telegram Mini App
- use the palette and tone from the repo, not default v0 styling
- respect the Quiet System design language
- warm light background
- calm teal accent
- minimal color noise
- mature, clear, personal tone
- not a generic SaaS dashboard
- not a BI panel
- not a grid of identical cards
- avoid obvious shadcn/v0 template feel
- avoid too many pills, badges, and repetitive card patterns

The dashboard should:
- feel like a personal return point
- show current state
- suggest one clear next step
- create a feeling of movement and calm progress
- keep community and gamification secondary to personal progress

Required sections:
1. hero with name, level, progress, one main CTA, one secondary CTA
2. quick actions
3. 3 compact overview stats
4. recently studied
5. recommended next rules
6. recent diary
7. achievements
8. notifications
9. quiet community preview
10. bottom nav

Content requirements:
- use realistic Russian copy
- make it feel like a real first user / founder dashboard
- include meaningful labels and helpful microcopy
- show one clear primary path through the screen

Design requirements:
- stronger hierarchy
- more premium and editorial feel
- believable Telegram Mini App proportions
- keep it clean and product-credible
- preserve calmness, not hype

Output:
- generate 3 distinct dashboard directions
- each direction should be visually strong and product-credible
- each should feel aligned with the repo’s Quiet System language
```

## Как использовать

1. Вставить prompt в `v0`
2. Попросить `3 distinct directions`
3. Сравнить варианты
4. Лучший вариант занести в [[obsidian/notes/Research Log|Research Log]]
5. Потом переносить в [[obsidian/notes/Figma Workspace|Figma Workspace]]
