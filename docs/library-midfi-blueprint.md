# Library Mid-Fi Blueprint

## Goal

Библиотека правил — это рабочий каталог, а не витрина. Экран должен быстро приводить пользователя к следующему полезному правилу.

Главные задачи экрана:

- дать быстрое понимание, что доступно
- помочь выбрать следующее правило
- дать фильтрацию без перегруза

## Visual thesis

`Тихая интеллектуальная библиотека с ясной навигацией`

Экран должен ощущаться:

- собранным
- функциональным
- спокойным
- не перегруженным карточками

## Hierarchy

### 1. Header

Содержит:

- заголовок раздела
- краткое описание
- строку поиска

### 2. Categories

Горизонтальный набор основных тем:

- `Страх`
- `Ожидание`
- `Внимание`
- `Выбор`
- `Состояние`
- `Радость`

Категории должны вести к быстрому старту, а не заменять поиск.

### 3. Filters and sorting

Поддерживают:

- формат
- статус
- сложность
- сортировку

Панель фильтрации не должна доминировать визуально.

### 4. Featured rule

Один акцентный блок с правилом, которое логично открыть следующим.

Содержит:

- title
- format / duration / difficulty
- короткую причину рекомендации
- CTA `Открыть правило`

### 5. Rules list

Список правил — основной рабочий слой экрана.

Каждая карточка должна показывать:

- title
- summary
- format
- duration
- difficulty
- tags
- status
- primary CTA

## Desktop composition

- header
- search
- categories row
- filters / sorting row
- featured rule block
- основной список правил

## Mobile composition

Последовательность:

1. header
2. search
3. categories
4. compact filters button / row
5. featured rule
6. rules list
7. bottom nav

На mobile поиск и категории важнее, чем большой featured block.

## Card rules

Карточка правила должна быть:

- компактной
- читаемой
- функциональной

Не должна быть:

- слишком высокой
- декоративной
- перегруженной pills

## Status rules

Статусы должны считываться мгновенно:

- `Не начато`
- `В процессе`
- `Изучено`
- `Применено`

Цвет — вторичен. Сначала всегда читаемый текст.

## Empty states

### No search results

- объяснить, что по текущему запросу ничего не найдено
- предложить сбросить фильтры

### No rules in category

- показать, что категория пока пуста
- предложить открыть все правила

## Copy rules

- короткие summaries
- utility-first названия
- без рекламного тона

## Anti-patterns

- не делать гигантскую сетку одинаковых карточек
- не поднимать filters выше смысла экрана
- не перегружать верх экрана служебными controls
