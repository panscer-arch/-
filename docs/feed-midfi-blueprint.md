# Feed Mid-Fi Blueprint

## Goal

Лента — это социальный слой Лайфкодинга. Она нужна не ради вовлечения любой ценой, а для обмена реальным опытом применения правил.

Экран должен помогать:

- делиться выводами
- показывать результаты применения
- видеть опыт других без визуального шума

## Visual thesis

`Спокойная интеллектуальная лента без ощущения шумной соцсети`

## Hierarchy

### 1. Header

Содержит:

- title
- краткое описание
- фильтры потока

Фильтры:

- `Все`
- `Подписки`
- `Популярное`
- `Новое`

### 2. Composer

Верхняя зона создания публикации.

Поддерживает:

- короткий пост
- вывод
- результат применения
- связь с правилом

Главный CTA:

- `Опубликовать`

### 3. Post stream

Каждый пост показывает:

- автора
- уровень
- количество достижений
- основной текст
- привязку к правилу, если есть
- действия: лайк, комментарий, сохранить, жалоба

### 4. Comments layer

Комментарии должны быть доступны, но не должны визуально доминировать над основным текстом поста.

## Desktop composition

- header
- filters row
- composer
- posts stream

## Mobile composition

1. header
2. compact filters
3. composer
4. post stream
5. bottom nav

## Post card rules

Пост должен быть:

- text-first
- лёгким для чтения
- спокойным по chrome

Не должен быть:

- перегруженным badges
- слишком ярким
- похожим на generic social network card

## Author meta rules

Метаданные автора должны быть полезными, но вторичными:

- имя
- уровень
- achievements count

Акцент всегда остаётся на содержании поста.

## Empty states

### No posts

- объяснить, что лента заполняется опытом участников
- предложить создать первый пост

### No posts in filter

- показать, что в выбранном фильтре пусто
- предложить вернуться к `Все`

## Copy rules

- utility-first
- без крикливого tone of voice
- формулировки должны поддерживать атмосферу умного сообщества

## Anti-patterns

- не делать вовлекающую соцсеть ради метрик
- не перегружать пост реакциями
- не делать мету автора сильнее самого текста
